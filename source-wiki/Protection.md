By default, Bending will detect and respect the following protection plugins:

### GriefPrevention

Players can only use bending inside land claims they can build in.

### Bolt

Players won't be able to affect protected blocks.

### Towny

Players can only use bending inside towns if they are allowed to build in them.

### WorldGuard

A custom `bending` state flag is registered that you can set to allow or deny bending inside a region.

For example, `/rg flag arena bending allow` will allow players to bend inside a region named "arena".
